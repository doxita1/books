# 读书精华库

这里用来整理每本书的主要内容、核心知识点和实际收获。目标是让你读完笔记，就能大概明白这本书讲什么、重要观点为什么成立，以及自己能学到什么。

当前重点是**股票投资、财务分析、交易与逻辑思考，目标是提高财商**。

## 从这里开始

- **想学某本书的知识点：**直接打开下方对应笔记。需要例子的概念就在原小节结合真实公司、历史事件或原始研究解释；无需例子的概念正常总结。
- **想知道怎么学、怎么做：**先读[《财商进阶合订本》](财商进阶合订本.md)。它把各书串成一条路线，包含资金基础、企业分析、估值、风险、思维检查、八周学习安排和五张工作卡。
- **想一次连续阅读全部笔记：**打开[《全部书籍笔记合订版》](全部书籍笔记合订版.md)，按目录跳转各书。
- **想深入某一本：**从下面的书籍索引进入。各书有主要内容地图、较完整的知识点讲解、例子、图解、误区和来源。
- **刚开始接触股票：**优先阅读《一本书读懂财报》→《聪明的投资者》→巴菲特股东信→《投资最重要的事》，再结合逻辑和认知书检查判断。交易书用于理解和研究另一套方法。
- **想复算共用的财报材料：**[美的与贵州茅台三季报图解](实战案例/2026三季报图解.md)保存完整计算、图表和原始公告，可作延伸阅读。各书中的案例讲解本身完整，不以打开本篇为前提。

合订本里的学习地图和回撤图保存在 `合订本配图/`。每本书的 Mermaid 图也配有文字说明，不支持图形渲染时仍可读懂。

11 本笔记按知识点组织讲解：重要机制充分展开，需要案例时直接讲清真实事实及其与概念的关系，并附来源；一般概念保持简洁。纯数学演示、真实研究中的假设题设、作者自述与已经核验的外部事实分别说明，不把虚构故事冒充现实。

## 怎么开始

把书籍文件放进这个目录，或直接告诉我书名和作者，就可以开始。也可以提供目录、章节或你特别想弄懂的部分。

- 有原书：根据实际读到的内容整理，标明分析范围。
- 只有部分章节：先整理这些章节，并写清还没有覆盖哪些内容。
- 只有书名：先确认具体书籍和可用资料；基于简介、目录或书评整理时，会注明资料来源，不当作全书精读。

不需要提前建文件夹或手工复制模板。后续分析时会自动为每本书建立目录、写入笔记，并更新下面的书籍索引。

```text
E:\book\
├─ README.md                 使用说明和书籍索引
├─ AGENTS.md                 后续分析时遵循的规则
├─ 财商进阶合订本.md         能力框架、学习路线与实践模板
├─ 全部书籍笔记合订版.md     全部独立笔记的连续阅读版
├─ 合订本配图\               学习地图与回撤图
├─ 实战案例\                 跨书使用的真实公司案例
│  ├─ 2026三季报图解.md      美的与茅台财报逐步讲解
│  ├─ 原始公告\             官方报告 PDF 原件
│  ├─ 图片\                 数据图与原表截图
│  └─ 数据\                 核验数字与可重跑绘图脚本
├─ _工具\更新合订版.py       从独立笔记更新连续阅读版
├─ _模板\
│  └─ 读书笔记.md             可复用的笔记结构
└─ 书名 - 作者\              开始分析具体书籍时创建
   ├─ 读书笔记.md             主要内容、知识点、难点和收获
   ├─ 原书\                  按需保存用户提供的原始文件
   └─ 图片\                  按需保存图解和配图
```

同一本书的补充分析继续写进原目录；不同版本需要区分时，在目录名中加版本信息。原始书籍文件会保留，已有文件不会擅自搬动或覆盖。

## 一份笔记会讲清什么

1. **快速了解**：一句话讲清这本书，以及最值得记住的几个结论。
2. **主要内容**：用自己的话串起全书的思路，不只是照抄目录。
3. **核心知识点**：解释概念、原理、例子、适用条件和容易误解的地方。
4. **难点图解**：有需要时，用关系图、流程图、对比表或图片配合解释。
5. **学到什么、怎么用**：把书中内容转成能理解的问题、能尝试的方法或能练习的能力。
6. **边界与来源**：区分作者观点、补充解释和仍待核实的内容。

默认用中文和通俗表达，先讲结论，再讲原因。图解服务于理解，不为凑形式配图；即使看不到图片，也能通过文字读懂主要意思。不同类型的书会调整结构，小说侧重故事、人物和主题，不强行套成方法清单。
